# Vice Harbor

An original open-world crime game set in Port Solana, a golden-hour coastal
city of palm boulevards, neon signs, a boardwalk and a pier. Roam on foot,
steal and drive cars, dodge traffic, outrun the police, and work a
three-mission story chain for the harbour fixer Marisol Vega.

## Run

Serve the `game/` folder with any static server, or from the repo root:

```
node serve.ts
```

then open http://localhost:8080.

## Controls

- WASD — move / drive
- Mouse, Q / E — orbit camera (E also enters / exits a car when on foot near one)
- Shift — sprint
- Click — fire pistol
- Space — handbrake
- Esc / P — pause

## Features

- Procedural city: towers with lit windows, invented neon signs, palms, ocean, boardwalk, pier, hideout garage
- Traffic AI, wandering pedestrians, wanted stars and police pursuit
- Hitscan pistol combat with muzzle flash and tracers
- Three missions: timed delivery, two-star escape, five-gate checkpoint run
- HUD with health, cash, wanted stars and a canvas minimap
- Title, pause and end screens; progress saved in localStorage
- WebAudio-synthesised engine, shots, sirens and UI sounds (starts on first input)
- Deterministic screenshot scenes: `?shot=start|play|chase|mission&seed=1`
